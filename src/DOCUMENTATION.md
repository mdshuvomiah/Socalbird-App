## 🎨 Style Guide

### Color Palette (Dark Theme)

**Primary Colors:**
- Primary Blue: `#3B82F6`
- Accent Cyan: `#06B6D4`
- Success Green: `#10B981`
- Warning Orange: `#F59E0B`
- Error Red: `#EF4444`

**Background Colors:**
- Base: `#0A0A0A`
- Card: `#111827`
- Elevated: `#1F2937`

**Text Colors:**
- Primary: `#FFFFFF`
- Secondary: `#F9FAFB`
- Muted: `#9CA3AF`
- Accent: `#6B7280`

**Border Colors:**
- Default: `#374151`
- Hover: Blue/Service color variants

**Gradients:**
- Blue to Cyan: `from-blue-600 to-cyan-500`
- Purple to Pink: `from-purple-600 to-pink-500`
- Green to Teal: `from-green-600 to-teal-500`
- Orange to Red: `from-orange-600 to-red-500`

### Typography Scale

**Headings:**
- H1: 3.75rem (60px) on desktop, 3rem (48px) on mobile
- H2: 3rem (48px) on desktop, 2.25rem (36px) on mobile
- H3: 2.25rem (36px)
- H4: 1.875rem (30px)
- H5: 1.5rem (24px)
- H6: 1.25rem (20px)

**Body Text:**
- Large: 1.25rem (20px)
- Base: 1rem (16px)
- Small: 0.875rem (14px)
- Tiny: 0.75rem (12px)

**Font Weights:**
- Normal: 400
- Medium: 500
- Semibold: 600
- Bold: 700

### Spacing System

**Base unit:** 4px

**Scale:**
- 0.5 = 2px
- 1 = 4px
- 2 = 8px
- 3 = 12px
- 4 = 16px
- 6 = 24px
- 8 = 32px
- 12 = 48px
- 16 = 64px
- 20 = 80px
- 24 = 96px

**Section Padding:**
- py-12: 48px (small sections)
- py-16: 64px (medium sections)
- py-20: 80px (large sections)

**Container:**
- Max-width: 1280px (6xl)
- Padding: 1rem (16px) on mobile, 2rem (32px) on desktop

### Button Styles

**Primary Button:**
```
bg-gradient-to-r from-blue-600 to-cyan-500
hover:from-blue-700 hover:to-cyan-600
text-white
rounded-lg
px-6 py-3
```

**Secondary Button:**
```
bg-gray-800
hover:bg-gray-700
text-white
rounded-lg
px-6 py-3
```

**Outline Button:**
```
border-2 border-blue-500
text-blue-400
hover:bg-blue-600/10
rounded-lg
px-6 py-3
```

**Ghost Button:**
```
text-blue-400
hover:text-blue-300
no background
```

### Card Styles

**Default Card:**
```
bg-[#111827]
border border-gray-800
hover:border-blue-500/50
rounded-lg
p-6 or p-8
transition-all duration-300
```

**Gradient Accent:**
Top border with gradient: `h-2 bg-gradient-to-r {color}`

### Responsive Breakpoints

- **Mobile:** < 768px
- **Tablet:** 768px - 1024px
- **Desktop:** > 1024px

**Grid Breakpoints:**
- Mobile: 1 column
- Tablet: 2 columns
- Desktop: 3-4 columns

## 🎨 Brand Voice Guidelines

**Tone:**
- Confident but not arrogant
- Clear and concise
- Premium but approachable
- Friendly and professional
- Technical but not jargon-heavy

**Writing Style:**
- Short sentences
- Benefit-driven (not feature-focused)
- Active voice
- Scannable formatting
- Use of concrete numbers/results

**Do's:**
✅ Focus on client outcomes
✅ Use real metrics when available
✅ Address pain points directly
✅ Provide clear next steps
✅ Be transparent about process

**Don'ts:**
❌ Overpromise
❌ Use vague claims
❌ Overcomplicate explanations
❌ Hide pricing completely
❌ Use excessive jargon

## 🔧 Technical Implementation Notes

**Framework:** React with TypeScript
**Styling:** Tailwind CSS v4
**UI Components:** shadcn/ui component library
**Icons:** Lucide React
**State Management:** React hooks (useState, useEffect)
**Routing:** Client-side routing with state management
**Theme:** Dark theme by default

**File Structure:**
```
/
├── App.tsx (Main router)
├── components/
│   ├── Navigation.tsx
│   ├── Footer.tsx
```
